# expynse
Expenditures tracker

## Windows usage:

- Install Python 3.10+.
- Open PowerShell in the project folder.
- python -m pip install -r requirements.txt
- Double-click run.bat or run: python -m app.main

## Notes:

- Database file expynse.db will be created in project root.
- PDF parsing uses heuristics; adjust parser.py for your bank's PDF layout.
